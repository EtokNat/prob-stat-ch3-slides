PREREQUISITE · 35 MIN

Coded Data — The Mean

One idea unlocks every coded-totals question for the rest of Paper 5:

code  →  compute  →  decode

Cambridge 9709 Paper 5 · Topic 5.1 · Ch 2 §2.3 (Coded data)

MOTIVATION

Why code at all?

Find the mean of  $101,\ 103,\ 104,\ 109,\ 113$.

Trick. Subtract $100$ from every value:

$1,\ 3,\ 4,\ 9,\ 13$

Mean of the coded values $= \dfrac{1+3+4+9+13}{5} = 6$.

Add $100$ back to decode: $\ \bar{x} = 6 + 100 = \mathbf{106}$.

The golden rule

Code → shrink the arithmetic.  Compute → mean of the small numbers.  Decode → reverse what you did.

CORE · ADDITION CODING

The shift: $y = x - b$

Every value slides by $-b$ on the number line → so does the mean.

Algebra you’ll keep reusing:

$\sum(x-b) = \sum x - nb$

(There are $n$ copies of $b$ being subtracted — once per data value.)

$\bar{x} = \dfrac{\sum(x-b)}{n} + b \qquad \bar{x} = \dfrac{\sum(x-b)f}{\sum f} + b$

Ungrouped on the left · grouped (frequency table) on the right — Key Point 2.3.

Worked 2.10 — grouped

Forty values of $x$ coded as $x-3$ into classes $0\text{--}18,\ 18\text{--}24,\ 24\text{--}32$ with frequencies $9,\ 13,\ 18$.

Mid-values $9,\ 21,\ 28 \Rightarrow \bar{x} = \dfrac{9{\cdot}9 + 21{\cdot}13 + 28{\cdot}18}{40} + 3 = \mathbf{24.45}$.

CORE · SCALE + SHIFT

When the code multiplies too: $y = ax - b$

Example: converting units, scaling percentages, or $y = 2x - 3$.

Undo in reverse order: add back $b$ first, then divide by $a$.

$\bar{x} = \dfrac{1}{a}\left[\dfrac{\sum(ax-b)}{n} + b\right]$

Key Point 2.4. Same rule: code → compute → decode — just two undo-steps instead of one.

Worked 2.12

For 20 values of $x$ with $\sum(2x-3) = 104$, find $\bar{x}$.

1Mean of coded $= \dfrac{104}{20} = 5.2$.
2So $2\bar{x} - 3 = 5.2$.
3Add 3 first: $2\bar{x} = 8.2$.
4Then divide by 2: $\bar{x} = \mathbf{4.1}$.
CORE · COMBINING GROUPS

Two coded datasets → one combined mean

Decode each $\sum$ back to raw $\sum x$ and $\sum y$ first. Never average the two coded means directly.

Worked 2.9 — boys & girls

10 boys: $\sum(b - 5) = 127$.   15 girls: $\sum(g + 5) = 351$. Find the combined mean age.

1Decode boys: $\sum b = 127 + 10(5) = 177 \Rightarrow \bar{b} = 17.7$.
2Decode girls: $\sum g = 351 - 15(5) = 276 \Rightarrow \bar{g} = 18.4$.

Watch the sign: $\sum(g+5) = \sum g + 5n$, so decoding subtracts $5n$.

3Combine: $\bar{\text{all}} = \dfrac{177 + 276}{10 + 15} = \dfrac{453}{25} = \mathbf{18.12}\ \text{yr}$.

This exact pattern reappears in Ch 3 §3.3 — only with $\sum x^2$ instead of $\sum x$ to combine variances.

EXAM-PROOFING

How examiners twist this

Four mutations. Spot the pattern, apply the rule, win the mark.

Twist 1 — sign of the constant. If given $\sum(x+7) = 420$, the “$+7$” means decoding subtracts $7n$: $\sum x = 420 - 7n$. If the sign is “$-7$”, you add $7n$. Always expand the bracket before you solve.
Twist 2 — different constants in two groups. E.g. one dataset coded $(x-10)$, another $(y+5)$. Decode each to raw $\sum x$, $\sum y$ separately, then combine. Mixing codes mid-calculation is the #1 wrong answer.
Twist 3 — solve for $n$ or $b$. Same identity, rearranged: from $\sum(x-b) = \sum x - nb$ and a given $\bar{x}$, isolate the unknown. The algebra is the whole question.
Twist 4 — “mean of coded” vs “$\sum$ of coded”. Read carefully. Mean of coded $= \sum(x-b)/n$ (already divided). $\sum(x-b)$ is the raw total (not divided). Different starting points — different arithmetic.
CLASSWORK · 7 MIN

Try it yourself

Twenty-five values of $z$ are such that $\sum(z - 7) = 275$. Find $\bar{z}$. [Exercise 2C Q2]

Hint: Twist 1 — what’s the sign? Then apply Key Point 2.3.

Verified final answer
1Mean of coded $= \dfrac{275}{25} = 11$.
2Decode: add $7$ back → $\bar{z} = 11 + 7$.

$\bar{z} = 18$.

A dataset of 20 values is denoted by $x$ where $\sum(x - 1) = 58$. Another dataset of 30 values is denoted by $y$ where $\sum(y - 2) = 36$. Find the mean of the 50 values of $x$ and $y$ combined. [Exercise 2C Q10]

Hint: Twist 2 — different constants. Decode each separately before combining.

Verified final answer
1Decode $x$: $\sum x = 58 + 20(1) = 78$.
2Decode $y$: $\sum y = 36 + 30(2) = 96$.
3Combine: $\bar{\text{all}} = \dfrac{78 + 96}{20 + 30} = \dfrac{174}{50}$.

Mean $= 3.48$.
