Coded Data — The Mean

Before we tackle spread in Chapter 3, master how coding affects the mean. One idea — shrink the numbers, do the arithmetic, undo the code — unlocks every coded-totals question for the rest of the paper.

Cambridge 9709 Paper 5 · Topic 5.1 · Ch 2 §2.3 (Coded data)

MOTIVATION

Why code at all?

Raw data can be large or awkward — long multiplications, easy slips. Coding replaces each value $x$ with a simpler $x - b$ by subtracting a convenient constant.

Textbook example (Ch 2 §2.3): find the mean of $101,\ 103,\ 104,\ 109,\ 113$.

Subtract $100$ from each → code is $1,\ 3,\ 4,\ 9,\ 13$.

Mean of coded $= \dfrac{1+3+4+9+13}{5} = 6$.  So $\bar{x} = 6 + 100 = \mathbf{106}$.

Golden rule: code → compute → decode. Never leave the answer in coded form.

CORE · ADDITION CODING

Shift by a constant $b$

Let $y = x - b$. Then every value moves by $-b$ along the number line, so the mean moves by $-b$ too.

$\bar{x} = \dfrac{\sum(x-b)}{n} + b \qquad \bar{x} = \dfrac{\sum(x-b)f}{\sum f} + b$

Key Point 2.3 (summary): $\ \bar{x} = \text{mean}(x - b) + b$.

Worked 2.10 (coded frequency table). 40 values of $x$ coded as $x-3$ into classes $0\text{--}18,\ 18\text{--}24,\ 24\text{--}32$ with frequencies $9,\ 13,\ 18$.

Using mid-values $9,\ 21,\ 28$: $\ \bar{x} = \dfrac{9\cdot 9 + 21\cdot 13 + 28\cdot 18}{40} + 3 = \mathbf{24.45}$.

CORE · MULTIPLICATION CODING

Scale and shift: $y = ax - b$

If the code also multiplies by $a$ (e.g. unit conversion, percentage), undo in reverse order: add back $b$ first, then divide by $a$.

$\bar{x} = \dfrac{1}{a}\left[\dfrac{\sum(ax-b)}{n} + b\right]$

Key Point 2.4 (summary): $\ \bar{x} = \dfrac{1}{a}\bigl[\text{mean}(ax-b) + b\bigr]$.

Worked 2.12. For 20 values of $x$ with $\sum(2x-3) = 104$, find $\bar{x}$.

Mean of coded $= \dfrac{104}{20} = 5.2$, so $2\bar{x} - 3 = 5.2 \Rightarrow 2\bar{x} = 8.2 \Rightarrow \bar{x} = \mathbf{4.1}$.

CORE · COMBINING GROUPS

Two coded datasets, one combined mean

Decode each $\sum$ back to $\sum x$ and $\sum y$ first, then combine. Never average the two coded means directly.

Worked 2.9. 10 boys satisfy $\sum(b-5) = 127$; 15 girls satisfy $\sum(g+5) = 351$.

Decode: $\sum b = 127 + 10(5) = 177$; $\ \sum g = 351 - 15(5) = 276$.

Boys' mean $= 17.7$ yr, girls' mean $= 18.4$ yr.

Combined mean $= \dfrac{177 + 276}{10 + 15} = \dfrac{453}{25} = \mathbf{18.12}\ \text{yr}$.

This is the exact trick Ch 3 §3.3 reuses for combined variance — only with $\sum x^2$ instead of $\sum x$.

CLASSWORK · 7 MIN

Try it yourself

Twenty-five values of $z$ are such that $\sum(z - 7) = 275$. Find $\bar{z}$. [Exercise 2C Q2]

Hint: addition coding — apply Key Point 2.3.

Verified final answer $\bar{z} = \dfrac{\sum(z-7)}{n} + 7 = \dfrac{275}{25} + 7 = 11 + 7$.
$\bar{z} = 18$.

A dataset of 20 values is denoted by $x$ where $\sum(x - 1) = 58$. Another dataset of 30 values is denoted by $y$ where $\sum(y - 2) = 36$. Find the mean of the 50 values of $x$ and $y$ combined. [Exercise 2C Q10]

Hint: decode each sum first, then combine (Worked 2.9 pattern).

Verified final answer Decode: $\sum x = 58 + 20(1) = 78$; $\ \sum y = 36 + 30(2) = 96$.
Combined mean $= \dfrac{\sum x + \sum y}{20 + 30} = \dfrac{78 + 96}{50} = \dfrac{174}{50}$.
Mean $= 3.48$.
